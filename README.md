Read the [writeup](https://gbkorr.github.io/r-bites/grr-claude/grr-claude.html) for more info! Plugin code by Claude Fable, with significant oversight.

Installation: copy the `skills` folder into your `~/.claude/` directory. I assume this only works on Linux, and maybe Mac, but it should be trivial to set up on other OSes; try a prompt like "I'd like to port the skill at github.com/gbkorr/apprentice to Windows and install it."
